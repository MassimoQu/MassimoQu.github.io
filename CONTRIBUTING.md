# Contributing to MassimoQu.github.io

Thank you for your interest in contributing to this academic homepage!

## How to Contribute

1. Fork this repository
2. Create a feature branch (`git checkout -b feature/improvement`)
3. Commit your changes
4. Push to the branch
5. Open a Pull Request

## Types of Contributions

- Fix typos or grammatical errors
- Improve documentation
- Add new content sections
- Enhance the site design
- Update publications list

## Style Guide

- Use Markdown for content
- Follow the existing layout patterns
- Add images to the `assets/` directory
- Keep publications format consistent
